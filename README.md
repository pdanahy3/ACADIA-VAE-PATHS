# ACADIA-VAE-PATHS

## Environment setup

This repository is intended to run with the **conda** environment **`ACADIA2026`**. When you start working on the project:

1. Activate the environment:

   ```bash
   conda activate ACADIA2026
   ```

2. Install Python dependencies from `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

Do this whenever you clone the repo or pull changes that update dependencies.
