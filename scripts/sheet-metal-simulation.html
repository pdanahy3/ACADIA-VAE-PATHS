512 × 512 Mesh Spring Simulation

The first and last u rows are fixed as anchor supports. Stretch springs follow mesh edges. Bending resistance uses second-neighbor springs. Plasticity lets edge rest lengths drift toward the current span after yield, so the sheet retains deformation.

This page uses ES modules. Browsers block loading a separate .js module from file://. Run serve.ps1 (runs serve_capture.py) in this folder, then open http://127.0.0.1:8765/sheet-metal-simulation.html. The dev server sends COOP/COEP so the page is cross-origin isolated: stretch constraints can use Web Workers + SharedArrayBuffer; otherwise the single-threaded solver runs.
